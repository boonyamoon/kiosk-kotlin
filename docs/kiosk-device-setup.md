# คู่มือตั้งค่าเครื่อง Kiosk: ล็อกหน้าจอ

แอป Kiosk กันไม่ให้ลูกค้าออกจากแอปด้วยการล็อกหน้าจอ เมื่อล็อกแล้ว ปุ่ม Home, Recents และแถบแจ้งเตือนจะใช้ไม่ได้ มีให้เลือก 2 แบบ

| แบบ | ใช้เมื่อ | ต้องใช้คอมพิวเตอร์ |
|---|---|---|
| **ปักหมุดแอป** (แบบหลัก) | ร้านดาวน์โหลดแอปจาก Play Store แล้วตั้งค่าเอง | ไม่ต้อง |
| **device owner** (ทางเลือกเสริม) | มีช่างติดตั้งให้ หรือร้านใช้ระบบจัดการเครื่อง (MDM) | ต้อง |

ถ้าไม่ได้ล็อกด้วยแบบใดเลย ลูกค้าจะปัดขอบจอเพื่อออกจากแอปได้ และหน้าจอจะมีแถบเตือน **"หน้าจอยังไม่ล็อก · แตะเพื่อปักหมุด"** อยู่ด้านบน

---

## แบบหลัก: ปักหมุดแอป

ใช้ได้กับทุกเครื่อง Android ไม่ต้องใช้คอมพิวเตอร์ ทำครั้งเดียวต่อเครื่อง

### ขั้นตอน

ในแอปมีหน้าแนะนำที่บอกว่าแต่ละขั้นทำแล้วหรือยัง และมีปุ่มพาไปหน้าตั้งค่าของ Android ให้ วิธีเปิด:

1. ที่หน้าแรก แตะโลโก้หรือชื่อร้าน 5 ครั้งภายใน 3 วินาที
2. ใส่ PIN พนักงาน
3. กด **วิธีตั้งค่าการล็อกหน้าจอ**

ขั้นตอนในหน้าแนะนำมี 4 ข้อ:

1. **ตั้งรหัสล็อกหน้าจอของเครื่อง** (PIN, รูปแบบ หรือรหัสผ่าน) พนักงานใช้รหัสนี้ตอนเลิกปักหมุด
2. **เปิด "ขอ PIN ก่อนเลิกปักหมุด"** ข้อนี้สำคัญที่สุด
   - เมนูอยู่ที่ ตั้งค่า > ความปลอดภัย > ปักหมุดแอป ให้เปิดทั้ง "ปักหมุดแอป" และ "ขอ PIN ก่อนเลิกปักหมุด"
   - ชื่อเมนูต่างกันตามยี่ห้อ ถ้าหาไม่เจอ ให้พิมพ์ "ปักหมุด" ในช่องค้นหาของตั้งค่า
   - บางเครื่องไม่ให้แอปตรวจข้อนี้ หน้าแนะนำจะขึ้นว่า "ตรวจไม่ได้" กรณีนั้นให้ตรวจในตั้งค่าเอง
3. **ตั้ง Kiosk เป็นแอปหน้าหลัก (Home)** เพื่อให้กดปุ่ม Home หรือปลดล็อกเครื่องแล้วกลับมาที่ Kiosk เสมอ หลังเลือกแล้ว แอปอาจกลับไปหน้าแรกเอง ถือว่าปกติ
4. **ปักหมุดแอป** กดปุ่มแล้วกดยืนยัน (เช่น "Got it") ในกล่องที่ Android ถาม

ตอนกดปุ่ม "เปิดการตั้งค่า" แอปจะเลิกปักหมุดชั่วคราวเพื่อให้เข้าตั้งค่าได้ ถ้าเปิด "ขอ PIN ก่อนเลิกปักหมุด" ไว้แล้ว เครื่องจะขึ้นหน้าล็อก ให้ใส่รหัสเครื่องก่อน

### หลังตั้งค่าเสร็จ

- **แอปขอปักหมุดเอง** ตอนเปิดแอป (รวมถึงหลังรีบูตหรืออัปเดต) ตอนกลับมาหน้าแรกหลังพนักงานออกจากโหมดล็อก และตอนที่หมุดหลุดไป พนักงานต้องกดยืนยันในกล่องที่ Android ถามทุกครั้ง เพราะ Android ไม่ให้แอปปักหมุดเองโดยไม่ถาม
- **ถ้ามีคนกดปฏิเสธ (เช่น "No thanks")** แอปจะไม่ถามซ้ำเอง (กันกล่องเด้งวนต่อหน้าลูกค้า) แต่จะแสดงแถบเตือนด้านบนแทน พนักงานแตะแถบเตือนเพื่อปักหมุดได้ทันที
- **ถ้าลูกค้าพยายามเลิกปักหมุด** (ปัดขึ้นค้างไว้ หรือกดค้างปุ่ม Back กับ Recents พร้อมกัน) เครื่องจะขึ้นหน้าล็อกที่ต้องใส่รหัส ลูกค้าจึงไปต่อไม่ได้ พนักงานปลดล็อกแล้วจะกลับมาที่ Kiosk และแอปจะขอปักหมุดอีกครั้ง

### สถานะในเมนูผู้ดูแล

| สถานะ | ความหมาย |
|---|---|
| ปักหมุดแอปอยู่ (เขียว) | ลูกค้าออกจากแอปไม่ได้ |
| ปักหมุดอยู่ แต่ยังเลิกปักหมุดได้ (ส้ม) | ยังไม่มีรหัสล็อกหน้าจอ หรือยังไม่เปิด "ขอ PIN ก่อนเลิกปักหมุด" ให้ทำตามหน้าแนะนำ |
| ไม่ได้ล็อก (แดง) | กด **ปักหมุดแอป** แล้วยืนยันในกล่องที่ Android ถาม |
| ปลดล็อกชั่วคราว (ส้ม) | พนักงานกดออกจากโหมดล็อกอยู่ (ดูหัวข้อด้านล่าง) |
| ล็อกอยู่ (device owner) | ใช้แบบ device owner ไม่ต้องปักหมุด |

ถ้ายังตั้งไม่ครบ ปุ่มในเมนูผู้ดูแลจะขึ้นว่า **วิธีตั้งค่าการล็อกหน้าจอ (ยังตั้งไม่ครบ)**

## การใช้งานประจำวัน (ทั้งสองแบบ)

### ออกจากโหมดล็อกชั่วคราว

ใช้เมื่อพนักงานต้องเข้าแอปอื่น เช่น ตั้งค่า Wi-Fi

1. เปิดเมนูผู้ดูแล แล้วกด **ออกจากโหมดล็อกหน้าจอ**
2. ถ้าใช้แบบปักหมุดและเปิด "ขอ PIN ก่อนเลิกปักหมุด" ไว้ เครื่องจะขึ้นหน้าล็อก ให้ใส่รหัสเครื่อง
3. สถานะจะเปลี่ยนเป็น "ปลดล็อกชั่วคราว" ปัดขอบจอเพื่อเรียกแถบระบบ แล้วเข้าแอปอื่นได้

### ล็อกกลับ

เครื่องจะล็อกกลับเมื่อเกิดอย่างใดอย่างหนึ่งต่อไปนี้ (แบบปักหมุดจะมีกล่องให้ยืนยัน):

- กด **กลับเข้าโหมดล็อก** ในเมนูผู้ดูแล
- ปิดเมนูผู้ดูแล (กดปุ่มย้อนกลับ)
- ไม่มีการใช้งานประมาณ 75 วินาที (ขึ้นคำถาม "ยังใช้เมนูผู้ดูแลอยู่ไหม?" หลัง 60 วินาที แล้วนับถอยหลัง 15 วินาที) จากนั้นแอปกลับหน้าแรก กรณีนี้ครอบคลุมตอนที่พนักงานลืมด้วย
- ออกไปใช้แอปอื่นนานเกินประมาณ 75 วินาที พอกลับมาที่ Kiosk จะล็อกแล้ว ถ้าต้องออกอีกให้ใส่ PIN พนักงานใหม่

### อัปเดตแอป

อัปเดตจาก Play Store ได้ตามปกติ ระหว่างอัปเดตแอปจะถูกปิดแล้วเปิดใหม่ ทำให้หมุดหลุด ถ้าเปิด "ขอ PIN ก่อนเลิกปักหมุด" ไว้ เครื่องจะขึ้นหน้าล็อก ให้ใส่รหัสเครื่องแล้วกดยืนยันปักหมุดอีกครั้ง

### ถอนแอป

Android ไม่ยอมให้ถอนแอปที่ปักหมุดอยู่ ให้ออกจากโหมดล็อกก่อน แล้วถอนที่ ตั้งค่า > แอป > Kiosk

## ทางเลือกเสริม: device owner

ล็อกได้แน่นที่สุด ไม่มีกล่องถามยืนยัน และไม่ต้องตั้งรหัสเครื่อง แต่ต้องใช้คอมพิวเตอร์ และ**เครื่องต้องไม่มีบัญชีใด ๆ** (Google, Samsung ฯลฯ) และไม่มีผู้ใช้อื่น ในทางปฏิบัติจึงต้องทำบนเครื่องใหม่หรือเครื่องที่ factory reset แล้ว เหมาะกับร้านที่มีช่างติดตั้งให้

### สิ่งที่ต้องมี

- คอมพิวเตอร์ที่ติดตั้ง [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) (คำสั่ง `adb`)
- สาย USB
- แท็บเล็ต Android 8.0 ขึ้นไป ที่ยังไม่ได้ลงชื่อเข้าใช้บัญชีใด

### ขั้นตอน

1. ตั้งค่าเครื่องครั้งแรก เชื่อม Wi-Fi และ**ข้าม**การลงชื่อเข้าใช้บัญชี Google
2. เปิดโหมดนักพัฒนา: ตั้งค่า > เกี่ยวกับแท็บเล็ต > แตะ "หมายเลขบิลด์" 7 ครั้ง แล้วเปิด USB debugging
3. ติดตั้งแอปด้วยไฟล์ APK: `adb install kiosk.apk` อย่าเพิ่งลงชื่อเข้าใช้ Play Store เพราะจะทำให้มีบัญชีในเครื่อง
4. ตั้ง device owner:

   ```sh
   adb shell dpm set-device-owner com.pos.kiosk/.KioskDeviceAdminReceiver
   ```

   ถ้าสำเร็จจะขึ้น `Success: Device owner set to package com.pos.kiosk/.KioskDeviceAdminReceiver` แอปที่เปิดอยู่จะล็อกเองทันทีที่สลับกลับมา ไม่ต้องรีบูต

5. เปิดแอปแล้วผูกเครื่องตามปกติ ในเมนูผู้ดูแลจะขึ้นว่า **ล็อกอยู่ (device owner)**
6. หลังจากนี้เพิ่มบัญชี Google ได้ถ้าต้องการ และควรปิด USB debugging

ถ้าคำสั่งในขั้นตอนที่ 4 ไม่สำเร็จ:

| ข้อความ | สาเหตุและวิธีแก้ |
|---|---|
| `... there are already some accounts on the device` | ยังมีบัญชีในเครื่อง ลบทุกบัญชีที่ ตั้งค่า > บัญชี หรือ factory reset |
| `... there are already several users on the device` | มีผู้ใช้อื่นหรือผู้เยี่ยมชม ลบออกที่ ตั้งค่า > ผู้ใช้หลายคน |
| `... device owner is already set` | มีแอปจัดการเครื่อง (MDM) อื่นเป็น device owner อยู่ ต้องเอาออกก่อน |
| `Unknown admin` | ยังไม่ได้ติดตั้งแอป หรือพิมพ์ชื่อ package ผิด |

### เลิกใช้ device owner / ถอนแอป

Android ไม่ยอมให้ถอนแอปที่เป็น device owner (`DELETE_FAILED_DEVICE_POLICY_MANAGER`) ให้ทำดังนี้:

1. เปิดเมนูผู้ดูแล กด **ปลด device owner** แล้วกดยืนยัน
2. จะขึ้นข้อความ "ปลด device owner แล้ว ตอนนี้ถอนแอปได้" จากนั้นแอปจะใช้แบบปักหมุดแทน
3. ถอนแอปที่ ตั้งค่า > แอป > Kiosk หรือใช้ `adb uninstall com.pos.kiosk`

ถ้าเปิดเมนูผู้ดูแลไม่ได้ (ไม่มีพนักงานที่มี PIN ใช้กับเครื่องนี้ได้) ทางเดียวที่เหลือคือ factory reset
